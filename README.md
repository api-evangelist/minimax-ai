# MiniMax (minimax-ai)

MiniMax is a Chinese foundation model company offering full-stack multimodal APIs: text generation, speech synthesis, voice cloning/design, image generation, video generation (Hailuo), and music generation. International base URL `https://api.minimax.io`; China base URL `https://api.minimaxi.com`.
